# box model

o css enxerga os elementos do html como caixas que possuem algumas propriedades.

## margin
margem é o espaço que distancia um elemento do outro, ou seja, é essa medida que faz um parágrafo ir para longe de uma imagem.

## border
para contornar um elemento podemos configuar uma borda, a borda nada mais é do que uma linha em volta do elemento que fica entre a margin e o padding

## padding
se a margin é o espaço externo de um elemento, o padding é o espaço interno,ele quem separa o conteúdo da borda e da margin.
